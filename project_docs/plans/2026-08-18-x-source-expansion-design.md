# X 来源首批扩容设计

## 目标

将 X 受控白名单从 35 个扩展到 51 个，增加 8 个研究/技术账号和 8 个专业资讯账号，提高 36 小时内的新鲜候选密度。

## 约束

- 保留现有 20 个 `primary` 官方来源不变。
- 新增账号全部 `official=false`；研究人员标记为 `research`，资讯作者和记者标记为 `media`。
- 不调整 `DAILY_X_TARGET_ITEMS`、`DAILY_X_MAX_ITEMS`、质量门禁或快照时效。
- 新增账号只提供候选线索，仍需通过事件聚类、事实证据绑定和 `DraftDecision`。
- 单测试账号继续每四小时抓取，先试运行三天，再根据成功率、新鲜度和最终入选率决定是否保留。

## 验证

- 配置必须包含 51 个大小写不敏感的唯一 handle。
- tier 分布必须为 `primary=20`、`research=18`、`media=13`。
- 16 个新增账号必须全部为非官方来源。
- 完整测试、`git diff --check` 和服务器配置加载必须通过。
